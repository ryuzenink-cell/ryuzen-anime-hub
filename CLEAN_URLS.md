# URLs limpas

As páginas principais foram movidas para pastas com `index.html`.

Exemplos:

- `/search/` em vez de `/search.html`
- `/anime/?id=1` em vez de `/anime.html?id=1`
- `/blog/` em vez de `/blog.html`
- `/blog/post/?post=blog/2026/05/boas-vindas-ao-blog-ryuzen.md` em vez de `/blog-post.html?...`

Os links internos e os links gerados por JavaScript foram atualizados para apontar para as novas rotas.
